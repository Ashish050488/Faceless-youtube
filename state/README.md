# state/ — live state (small text files only)
| File | What |
|---|---|
| `videos.json` | every video: slug, slot, status (scripted/uploaded/live/cancelled), video_id, times — the source of truth |
| `schedule.md` | when things publish (IST + UTC) and why |
| `sessions.md` | which chat (session id) does what — update when one is replaced |
| `learnings.md` | what we learned, newest first; only what changes decisions |
| `brand.md` | palette, logo, watermark (locked) |
| `competitor_watch/` | measured competitor data |
| `analytics/` | stats snapshots (JSON) |
| `instagram_plan.md`, `instagram_posts.json` | Instagram plan + post log (Instagram chat) |
| `policy_notes.md` | YouTube monetisation/policy notes |
| `music_registry.json` | music beds already used (no repeats) |
