# For any AI agent working in this repo
Read **CLAUDE.md** first (rules), then **README.md** (repo map), then only the file for your job:
- writing a video script → WORKFLOW.md + SCRIPT_STYLE.md + VERDICT.md + scripts/README.md
- building a video → render/README.md + PRODUCTION_SPEC.md + render/kit/OBJECTS.md
- Instagram → INSTAGRAM_POSTS.md
- uploading / stats → yt/README.md
Never commit keys or media. Work on `main`; media only on `handoff/*` branches.
